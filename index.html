URSACORP Apps

Documentation for our four apps for Jira Cloud. Each page covers how the app works, what it does, how to set it up, and step-by-step instructions for verifying that it works on your own site.

All four are built on Atlassian Forge and run entirely on Atlassian's infrastructure, inside your own Jira site. They read Jira data through Atlassian's APIs using the permissions of the person viewing the page, render it in the browser, and discard it. None of them makes a network call to any host outside Atlassian, and none of them stores your data anywhere.

The apps

Issue Aging Chart

A dashboard gadget that plots every in-progress issue by how long it has been in progress, with guide lines drawn from the cycle times your project actually recorded over the last 90 days.

Epic Lens

A project page showing the active sprint as one dense, foldable table grouped by epic, with progress on every epic and a keyboard-first interface.

Sprint Countdown

A dashboard gadget showing a large, glanceable countdown to the end of the active sprint on a board you choose, or to any date you set yourself.

Worklog Pivot

A project page that turns logged time into a pivot table: authors down the side, epics across the top, totals that reconcile, and CSV export.

Common to all four

Installing

Install from the Atlassian Marketplace listing, or in Jira go to Apps → Explore more apps, search for the app by name, and choose Get app. Installation needs Jira administrator rights. Nothing else has to be configured at the site level.

Permissions

Every app requests read-only permissions and none requests any write permission. Each app asks for the smallest set its Jira API calls actually require, and the exact list is on that app's page below and on its Marketplace listing. Every request runs as the signed-in viewer, so an app can only ever show you what you could already open in Jira yourself.

Privacy

These apps do not collect, store, transmit or sell any of your data. See the privacy policy.
